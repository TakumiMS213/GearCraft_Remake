Native EnemySpawner planning methods generate a seeded fixed spawn replay using native prefabs/AI/physics and 1/60 game delta. Physics step unchanged. Actual spawn time/position recorded separately. Bot controls movement/aim; aim compensates muzzleOffset. HP/GATE replenished each frame, so these are offensive throughput tests, not human ordinary clear times or survival proofs. Each wave resets. STR=ACC=2*(day-1), no unique reward cards, no PunkDrive, no BOOST. Upgrade effects are read from actual UpgradePartSO assets and applied through StatusManager.RecalculateUpgradeEffects(parts), with no direct fixed bonusDamage assignment. moduleDamage is separate crafted module damage. Native spread/muzzle/speed/configuration/line-hit/recoil methods are invoked; double-shot duplicates the native branch. Cooldown uses the native private timer and one CoolTimeUpdate call after each game frame including no-target frames; shots counts projectiles (or melee/line attacks), attack_events counts attacks. Original PlayerPrefs are not restored by this script; root restoration is required after all tests. No crafting/ED time counted.
